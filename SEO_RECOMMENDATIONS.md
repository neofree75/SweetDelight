# SEO Odporúčania pre Marsela Bakery

## ✅ Implementované

### 1. Meta tagy a Open Graph
- ✅ Dynamické meta tagy pre každú stránku
- ✅ Open Graph tagy pre sociálne siete
- ✅ Twitter Card tagy
- ✅ Geo tagy pre lokálnu SEO
- ✅ Canonical URLs

### 2. Structured Data (Schema.org)
- ✅ Organization/Bakery schema
- ✅ Product schema pre produktové stránky
- ✅ BreadcrumbList schema
- ✅ GeoCoordinates

### 3. Sitemap a Robots.txt
- ✅ Dynamický sitemap.xml s produktmi
- ✅ Robots.txt s pravidlami pre vyhľadávače
- ✅ Automatické generovanie produktových URL

### 4. Rozšírené vyhľadávanie
- ✅ URL parametre pre vyhľadávanie (q, category, page, minPrice, maxPrice, inStock, sort)
- ✅ Pokročilé filtre (cena, dostupnosť)
- ✅ Zoraďovanie produktov
- ✅ Rozšírené vyhľadávanie (názov, popis, kategória)

## 📋 Ďalšie odporúčania

### 1. Technické SEO

#### Performance optimalizácia
- [ ] Implementovať lazy loading pre obrázky
- [ ] Optimalizovať veľkosť obrázkov (WebP formát)
- [ ] Implementovať code splitting
- [ ] Pridať service worker pre caching
- [ ] Optimalizovať font loading (font-display: swap)

#### Core Web Vitals
- [ ] Monitorovať LCP (Largest Contentful Paint) - cieľ < 2.5s
- [ ] Monitorovať FID (First Input Delay) - cieľ < 100ms
- [ ] Monitorovať CLS (Cumulative Layout Shift) - cieľ < 0.1

#### Mobile-first
- [ ] Testovať na rôznych zariadeniach
- [ ] Optimalizovať touch targets (min 44x44px)
- [ ] Zabezpečiť responzívne obrázky

### 2. Obsahové SEO

#### Blog/Články
- [ ] Vytvoriť blog sekciu s receptami a tipmi
- [ ] Pravidelné publikovanie obsahu (1-2x týždenne)
- [ ] SEO-friendly URL štruktúra: `/blog/nazov-clanku`
- [ ] Interné linkovanie medzi článkami

#### Produktové popisy
- [ ] Rozšíriť produktové popisy (min 200 slov)
- [ ] Pridať FAQ sekciu na produktové stránky
- [ ] Pridať recenzie a hodnotenia produktov
- [ ] Pridať "Súvisiace produkty" sekciu

#### Lokálne SEO
- [ ] Vytvoriť Google Business Profile
- [ ] Získať recenzie na Google Maps
- [ ] Pridať lokálne kľúčové slová do obsahu
- [ ] Vytvoriť stránku "Kde nás nájdete" s mapou

### 3. Link Building

#### Interné linkovanie
- [ ] Pridať relevantné interné linky v článkoch
- [ ] Vytvoriť breadcrumb navigáciu (už implementované v structured data)
- [ ] Pridať "Súvisiace produkty" na každú produktovú stránku

#### Externé linky
- [ ] Získať backlinky z lokálnych adresárov
- [ ] Partnerstvo s inými cukráreniami/obchodmi
- [ ] Guest posting na relevantných blogoch
- [ ] Zdieľanie na sociálnych sieťach

### 4. Analytika a monitorovanie

#### Google Analytics 4
- [ ] Implementovať GA4 tracking
- [ ] Nastaviť conversion goals (objednávky)
- [ ] Monitorovať bounce rate a time on page
- [ ] Trackovať e-commerce udalosti

#### Google Search Console
- [ ] Pripojiť Google Search Console
- [ ] Monitorovať indexovanie stránok
- [ ] Kontrolovať chyby (404, crawl errors)
- [ ] Analyzovať search queries a CTR

#### Ďalšie nástroje
- [ ] Google Tag Manager pre jednoduchšie tagovanie
- [ ] Hotjar alebo podobný nástroj pre heatmaps
- [ ] PageSpeed Insights monitoring

### 5. Sociálne siete

## 📊 Kľúčové metriky na sledovanie

- **Organic traffic** - Počet návštev z vyhľadávačov
- **Keyword rankings** - Pozície v Google
- **Conversion rate** - % návštevníkov, ktorí objednajú
- **Bounce rate** - % návštevníkov, ktorí odídu hneď
- **Average session duration** - Ako dlho návštevníci zostávajú
- **Pages per session** - Koľko stránok navštívia
- **Core Web Vitals** - Performance metriky
